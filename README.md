# Pixelrus server resource pack

The pack is distributed only as the release asset `pixelrus-release-pack.zip`
(see Releases). The plain unpacked source is intentionally not kept on the
main branch.

Players receive it automatically on join via the server's `resource-pack`
setting. To update: publish a new release asset and set the new URL + SHA-1 in
each server's `server.properties`.
